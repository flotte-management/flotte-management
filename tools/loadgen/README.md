# Load generator (Grafana demo)

Minimal load generator to create realistic traffic on the local fleet APIs.
It calls read endpoints, creates missions, updates vehicle/driver status, and
pushes GPS positions. It also injects 4xx and 5xx errors at low rate.

## Requirements

- Python 3.10+

## Install

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python loadgen.py
```

Run in background:

```bash
nohup python loadgen.py > loadgen.log 2>&1 &
```

## Auth

You can pass an access token directly:

```bash
REQUEST_TIMEOUT_SEC=25 API_TOKEN=YOUR_JWT python loadgen.py
```

Or ask Keycloak for a token (password grant):

```bash
KEYCLOAK_URL=http://localhost:8080 \
KEYCLOAK_REALM=flotte-management \
KEYCLOAK_CLIENT_ID=flotte-frontend \
KEYCLOAK_USERNAME=admin.flotte \
KEYCLOAK_PASSWORD=YOUR_PASSWORD \
python loadgen.py
```

## Config (env)

- GATEWAY_URL: default http://localhost:4000/graphql
- VEHICLE_SERVICE_URL: default http://localhost:8081
- DRIVER_SERVICE_URL: default http://localhost:8000
- MAINTENANCE_SERVICE_URL: default http://localhost:8001
- MISSION_SERVICE_URL: default http://localhost:3005
- LOCATION_SERVICE_URL: default http://localhost:3003
- MIN_DELAY_SEC, MAX_DELAY_SEC: sleep between requests (default 0.2, 1.5)
- ERROR_RATE: probability for error requests (default 0.08)
- POSITION_RATE: probability to push a GPS point (default 0.2)
- BUSINESS_RATE: probability for business mutations (default 0.25)
- READ_RATE: probability for read traffic (default 0.55)
- REQUEST_TIMEOUT_SEC: default 5
- LOG_EVERY: print stats every N requests (default 25)

## Notes

- 5xx errors are generated by sending invalid mission dates (end < start)
  to the mission-service. If your local API rejects that with 4xx, lower
  ERROR_RATE or disable errors with ERROR_RATE=0.
